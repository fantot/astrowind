如果你同时订阅 Grok、Cursor 和 X Premium，过去最麻烦的不只是贵，而是三套账号、三张账单和三种完全不同的额度规则。

SpaceXAI 现在推出 **The X Subscription**，把 Grok、Cursor 和 X 权益合并到同一个订阅里。新方案有免费档，以及 Plus、Premium、Super、Ultra 四个付费档，月费分别为 8、30、100 和 200 美元。

第一眼看过去，30 美元的 Premium 很有吸引力：官方把它描述成原先 SuperGrok、Cursor Pro 和 X Premium+ 的组合，三者过去单独购买合计约 90 美元。

但“打包价更低”不等于每个人都更划算。这里有几个很容易在购买页面上看漏的细节：Grok 和 Cursor 共用一份周额度；Cursor 里的 Claude、GPT 等第三方模型不包含在套餐内；8 美元 Plus 没有 Grok Bot；而且账号一旦完成统一，官方说明目前不能撤销。

这篇文章不只列价格，而是帮你算清楚：什么人值得换，什么人继续保留旧套餐反而更合适。

> 本文依据 SpaceXAI 2026 年 10 月 2 日公告及 10 月 11—12 日更新的官方文档整理。订阅仍在全球逐步推出，税费、地区可用性、实际额度和促销以账户结算页为准。

## 先纠正一个容易混淆的说法：不是五个付费档

官方一共列出五个等级，但其中一个是 Free 免费档。真正需要付款的是四档：

| 套餐    |     月付 |       年付折算 |      包含用量 | Grok Bot |
| ------- | -------: | -------------: | ------------: | -------- |
| Free    |   0 美元 |         0 美元 |          有限 | 不含     |
| Plus    |   8 美元 |   约 7 美元/月 |      基础额度 | 不含     |
| Premium |  30 美元 |     25 美元/月 |  Plus 的 4 倍 | 包含     |
| Super   | 100 美元 |  约 84 美元/月 | Plus 的 15 倍 | 包含     |
| Ultra   | 200 美元 | 约 167 美元/月 | Plus 的 50 倍 | 包含     |

年付价格分别为 80、300、1000 和 2000 美元。表里的 4 倍、15 倍、50 倍是相对于 Plus 的套餐级别，不是“可以发送固定数量的消息”。不同功能消耗额度的速度可能不同，购买前仍要看账户中显示的实时用量说明。

付费方案在连接个人 X 账号后，会提供对应的 X Premium 权益。官方公告还提到勾选标记、创作者工具、减少广告等权益，更高档位可移除时间线广告。具体广告范围和地区差异应以 X 账户页面为准，不要只凭一句“免广告”下单。

## 细节一：Grok 和 Cursor 不是各送一份额度

The X Subscription 的核心规则是 **共享周额度池**。

你在 Grok 里聊天、生成图片、使用语音，或者在 Cursor 中调用套餐覆盖的 Grok 模型，消耗的都是同一份额度。Premium 标注“4x”，不是 Grok 有 4x、Cursor 再有 4x，而是两边一起使用这 4x。

这对使用习惯不同的人影响很大。

如果你平时写代码多、聊天少，共享额度反而灵活，因为闲置的 Grok 额度可以全部用于 Cursor。反过来，如果白天让 Cursor 长时间跑 Agent，晚上再用 Grok 做大量图片或视频，两个场景会互相挤占额度。

额度按周刷新，而不是每月一次性发放。好处是一次重度任务不会让你整个月都无法使用；坏处是不能把几周没用的额度攒到月底做大项目。

购买后应该做的第一件事，不是立刻打开所有功能，而是到 `grok.com/dashboard` 找到 Usage 页面，确认：

1. 本周剩余额度；
2. 下次刷新时间；
3. 哪些功能计入共享池；
4. 是否开启了额外用量和自动充值。

## 细节二：Cursor 里的 Claude 和 GPT 要另外付费

很多人看到“Grok + Cursor”后，会自然理解为 Cursor 中能选择的所有模型都包含在月费里。官方文档明确说明：不是。

套餐包含的是符合条件的 SpaceXAI 第一方用量，也就是 Grok 模型在 Grok 和 Cursor 中的调用。Cursor 里的 Claude、GPT 等第三方模型，从第一次使用起就消耗 **Additional Usage** 预付余额，按相应 API 标价结算。

第三方模型目前从 Premium 及以上档位提供。Plus 用户即使有 Cursor 用量，也不代表可以在套餐内免费使用 Claude 或 GPT。

如果你购买 Cursor 的主要原因是长期使用 Claude 写代码，不能只比较 30 美元月费。更接近真实的计算方式是：

```text
每月总成本 = X 订阅费 + 第三方模型额外用量 + 税费
```

建议在开通第三方模型前做两项设置：

- 给 Additional Usage 设置每月消费上限；
- 不需要自动补充余额时，关闭 Auto Top-up。

官方文档特别提醒，预付余额和月度消费上限是两个不同开关。账户里还有余额，不代表超过消费上限后还能继续；打开自动充值，也不代表系统会自动替你设置一个安全上限。

## 细节三：8 美元 Plus 没有 Grok Bot

Plus 适合轻度聊天、偶尔生成内容、体验 Cursor 第一方模型，以及需要基础 X 权益的人。但它不包含 Grok Bot。

Grok Bot 是能够持续执行任务的 Agent，不只是普通聊天界面。它可以处理文件、浏览器、代码和多步骤工作流，使用门槛从 Premium 开始。

所以，如果你购买的主要动机是“让 Agent 替我持续做事”，最低需要看 30 美元档，而不是 8 美元档。反过来，如果你只需要日常问答和偶尔写代码，没有必要为了一个从不使用的 Bot 升级。

可以用下面三个问题判断：

```text
我是否每周都用 Cursor 写代码？
我是否需要 Grok Bot 连续执行多步骤任务？
我是否真的使用 X Premium 的创作者或广告权益？
```

只命中第一个且用量轻，Plus 可能够用；命中前两个，Premium 更接近实际需求；三个都命中，打包订阅的价值才真正体现出来。

## 细节四：统一账号是永久操作，旧订阅不会在所有渠道自动取消

现有 SuperGrok、Cursor 或 X Premium 用户可以保留原套餐，也可以选择统一。官方并没有要求所有老用户立即迁移。

一旦完成统一，官方文档写明该操作目前是永久的，支持团队也不能恢复为统一前的状态。因此不要只为了看促销价格就点击确认，先检查旧套餐权益和剩余周期。

正常情况下，符合条件的旧订阅会在结算时取消，未使用部分按比例退款，新套餐则立即按全额扣款。退款和新扣款是两笔独立交易，银行卡上可能先看到新套餐扣款，几天后才看到退款。

应用商店订阅更容易出问题：

- Cursor 如果通过 Apple App Store 订阅，系统不能替你取消，需在 iPhone 或 iPad 设置中手动关闭续费；
- Grok、Grok Bot 或 X Premium 的 Apple 退款由 Apple 决定；
- Google Play 用户完成迁移后，也应检查原订阅是否仍设置为自动续费。

最稳妥的迁移顺序是：

1. 截图保存现有套餐、到期日和付款渠道；
2. 查看账户里是否已出现官方 Unify 入口；
3. 核对系统准备取消的旧订阅；
4. 确认退款金额和新套餐立即扣款金额；
5. 完成后分别检查 Apple、Google Play 和银行卡自动续费；
6. 一周内再次查看账单，确认没有重复扣款。

## 四类用户怎么选

### 只想低价体验 Grok：先用 Free 或 Plus

不要因为“打包”就默认 Premium。免费档已经提供每日 Grok 使用和 Cursor 入门额度。确认自己每周都会用，再升级 8 美元 Plus。

### 同时使用 Grok 和 Cursor：Premium 是主力档

Premium 才开始包含 Grok Bot，额度为 Plus 的 4 倍，也开放 Cursor 第三方模型入口。对于个人开发者、内容创作者和日常使用 Agent 的用户，它是最值得先观察一个月的档位。

注意，第三方模型仍另付费。第一月不要年付，先看 Usage 页面中的真实消耗。

### 长时间运行 Agent：Super 可能比频繁补额度清楚

如果 Premium 每周都在刷新前耗尽，并且额外充值稳定超过套餐差价，再考虑 Super。不要仅凭“15x”升级，先连续记录两到三周消耗。

### 团队重度开发：比较 Ultra 和企业合同

团队版 Premium、Super、Ultra 按席位收费，可以混合席位等级，并提供集中账单、使用分析和管理控制。真正需要持续云端 Agent、统一权限和审计的团队，才有理由考虑 200 美元档。

团队里每个付费席位有自己的周额度，不能把所有人的周额度集中给某一个重度用户；团队共享的是额外用量的预付余额。采购时要把这一点算进去。

## 一张下单前的最终检查表

```text
[ ] 我每周都会使用 Grok 和 Cursor 中的至少两个产品
[ ] 我知道 Plus 不含 Grok Bot
[ ] 我知道 Claude、GPT 等第三方模型另计费
[ ] 我接受 Grok 与 Cursor 共用周额度
[ ] 我已设置额外用量上限，并检查自动充值
[ ] 我已确认税费、汇率和银行卡境外支付成本
[ ] 我已记录旧订阅的付款渠道和到期日
[ ] 我明白账号统一完成后目前不能撤销
```

The X Subscription 对真正同时使用 Grok、Cursor 和 X 的人，确实可能把三张账单压成一张更便宜的账单。但如果你只用其中一个产品，打包里没用到的权益仍然是浪费。

判断它值不值，不要看“原价合计 90 美元”，要看你过去一个月实际打开过哪些功能、用掉多少额度，以及第三方模型最终增加了多少账单。
