## 一、ChatGPT 是什么

ChatGPT 是 OpenAI 提供的 AI 助手。你可以使用自然语言给它下达任务，它会根据对话上下文生成回答。

常见用途包括：

- 写作：起标题、列提纲、润色、改写和检查语病；
- 办公：总结会议记录、撰写邮件、制作计划和整理表格；
- 学习：解释概念、设计练习、模拟问答和制定学习计划；
- 研究：归纳资料、比较观点、提出检索方向；
- 编程：解释代码、定位错误、编写脚本和拆解开发任务；
- 多模态：理解图片、分析上传文件、进行语音交流和生成图片。

它的回答看起来很自然，但不代表所有内容都正确。涉及医疗、法律、财务、合同、数据和实时信息时，必须核对原始来源。

## 二、使用前需要准备什么

### 1. 使用自己的账号

长期使用建议保留账号的完整控制权，包括邮箱、登录方式、恢复方式和双重验证。不要把重要资料放在来源不明的共享账号里。

### 2. 确认所在地区是否受支持

OpenAI 会维护 ChatGPT 支持国家和地区列表，并提醒从不受支持的地区访问或提供访问可能导致账号被封禁或暂停。因此，不建议通过频繁切换地区、异常网络环境或来历不明的账号规避平台规则。

### 3. 保护敏感信息

不要在对话中直接提交：

- 银行卡号、密码和验证码；
- 身份证件完整照片；
- 未脱敏的客户名单和商业机密；
- 公司内部密钥、Token 和生产数据库内容；
- 未经授权的个人隐私信息。

上传合同、报告或表格前，可以先删除姓名、电话、地址、账号等敏感字段。

免费版适合低频问答、简单写作和体验基础功能。如果你只是偶尔使用，不必急着付费。

还要特别注意：**ChatGPT Plus 不包含 OpenAI API 额度。** ChatGPT 网页/应用订阅和 API 平台采用两套独立的计费系统。如果你的目标是给程序调用模型，需要单独配置 API 账单。

## 四、ChatGPT 的正确提问方式

很多人觉得 ChatGPT 回答空泛，原因通常不是模型完全不会，而是任务描述缺少必要信息。

一个实用提示词可以由五部分组成：

1. **目标**：最终要得到什么；
2. **背景**：为什么做、给谁使用；
3. **材料**：模型需要参考的文字、数据或文件；
4. **限制**：长度、语气、时间、不能出现的内容；
5. **格式**：表格、清单、Markdown 或分步骤输出。

例如，不要只说：

> 帮我写一个推广文案。

可以改成：

> 为一项面向自由职业者的 AI 工具咨询服务写首页文案。读者了解 ChatGPT，但担心充值和使用风险。语气专业、克制，不承诺永久稳定。输出一个 20 字以内标题、一段 80 字介绍和 3 个卖点。

如果结果不满意，不必重新开始一段对话。可以继续告诉它哪里不对：

- “第二段太像广告，请改得客观一些”；
- “保留结构，但把专业术语换成新手能懂的表达”；
- “列出你不确定的事实，不要自行补充”；
- “先问我三个关键问题，再生成最终结果”。

## 五、五个最实用的使用场景

### 场景 1：长文总结

上传文档后，不要只要求“总结一下”。最好说明读者、用途和输出结构：

> 阅读这份材料，分别输出核心结论、关键数据、存在争议的观点和需要进一步核实的问题。每一项注明对应章节，不要补充材料中没有的信息。

### 场景 2：写作与润色

让 ChatGPT 先分析原文的问题，再决定如何修改，通常比直接要求重写更稳定：

> 先判断这段文字在逻辑、信息密度和语气上的问题，再给出修改稿。保留事实和个人表达，不添加无法验证的数据。

### 场景 3：表格和数据分析

上传表格前先检查是否包含隐私数据。分析时明确指标：

> 检查销售数据中的缺失值和异常值，按月份计算收入、订单量和客单价，找出变化最大的三个时间段，并说明你的计算方法。

### 场景 4：学习新知识

可以让 ChatGPT 充当循序渐进的教练：

> 我没有编程基础，希望用两周理解 Python 数据处理。每天可以学习 40 分钟。请先测试我的基础，再设计每日任务；每次只讲一个知识点，并提供练习和答案。

### 场景 5：代码与自动化

描述运行环境、输入、预期结果和报错信息：

> 这是一个 Astro 7 + TypeScript 项目。下面组件在构建时出现错误。请先解释根因，再给最小修改方案，不要重构其他文件。修改后列出验证命令。
