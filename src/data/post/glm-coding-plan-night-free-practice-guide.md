9 月 3 日至 9 月 20 日，智谱为 GLM Coding Plan 付费用户推出夜间畅用活动。每天北京时间 23:00 至次日 9:00，使用 GLM-5.3-Flash 时，通过 ZCode 调用不消耗套餐额度；在套餐支持的其他 Agent 中使用，则获得双倍额度。

活动听起来像“深夜无限续杯”，但如果只是为了免费而熬夜对话，省下的是 Token，损失的可能是第二天的注意力。

更好的思路是把它当成一间限时开放的 AI 实验室。

## 先看清活动边界

这次活动覆盖所有付费 Coding Plan 用户，但只针对 GLM-5.3-Flash。错峰时间使用 GLM-5.3，仍然按套餐正常扣除。

GLM-5.3-Flash 是 GLM-5 系列首个原生多模态模型，适合代码生成、代码理解、问题修复，也能处理截图、文档和部分专业任务。ZCode 已将它作为订阅用户可直接使用的内置模型。

“免费使用”也不代表没有并发、系统负载、上下文或产品规则限制。开始大型任务前，最好先看账户用量页和活动页面的最新说明。

## 最有效的用法：白天设计任务，晚上批量执行

很多人使用 AI 编程工具时，时间都耗在临时想需求、反复改口和修复不清楚的错误上。夜间活动要真正省钱，可以把工作分成两个阶段。

### 白天：准备一张任务卡

任务卡只需写清五件事：

1. 要解决的真实问题；
2. 当前项目能否正常运行；
3. 允许修改哪些目录；
4. 完成后必须通过哪些检查；
5. 哪些操作必须先征得确认。

例如，不要写“帮我做一个记账网站”，可以写成：“在现有 Astro 项目中新增月度支出页面，读取本地 JSON，手机端可用，不引入数据库，完成后运行构建并说明修改文件。”

### 晚上：让 Agent 跑完整闭环

进入活动时段后，再让 ZCode：

- 阅读项目结构和已有约定；
- 给出三到五步计划；
- 逐步修改代码；
- 运行检查和构建；
- 根据报错修复；
- 最后生成变更摘要。

这比连续问几十个零散问题更接近真实开发，也更能检验模型的长任务稳定性。

### 第二天：只复盘三个指标

不要用“感觉挺聪明”评价模型，记录：

- 第一次构建是否通过；
- 你手动修改了多少处；
- 哪个环节最容易偏离要求。

连续做三晚，你会得到一份比排行榜更适合自己的模型使用说明。

## 初学者可以做的三个项目

### 项目一：整理一个重复文件任务

让 Agent 扫描测试目录，生成重命名方案，但先不要执行。确认方案后再批量处理，并生成操作日志。这能练习权限边界和可撤销操作。

### 项目二：给现有网站补一个小功能

例如增加 FAQ、文章标签筛选或站点地图检查。重点不是功能多复杂，而是要求它先读现有组件，避免重复造轮子。

### 项目三：修复真实报错

保留原始日志，让模型先解释根因，再提出最小修改，最后运行测试。不要直接复制一段网上的“标准答案”，真实错误更能训练你判断 AI 是否靠谱。

## 免费时段最容易踩的坑

第一，不要把整个电脑目录都交给 Agent。只开放项目文件夹，并使用 Git 保存可回退版本。

第二，不要为了“用回本”制造无意义任务。输出很多代码不等于学会了编程；能解释修改原因、发现错误和完成验收，才算有效练习。

第三，不建议长期熬夜。可以在晚上准备好任务后让工具执行，次日检查结果；涉及付款、删除、部署和密钥的步骤应等待人工确认。

## 写在最后

模型促销会结束，但训练方法可以留下。把免费额度变成三个真实项目、一套任务模板和一张复盘表，比单纯跑掉几亿 Token 更有价值。

AI 编程学习的关键，不是让模型替你写得更多，而是逐渐学会判断：它改了什么、为什么这样改、结果是否真的可用。
