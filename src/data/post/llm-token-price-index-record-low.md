大模型行业终于有了一个越来越像“油价”的数字。

Silicon Data 公布的 LLM Token Expenditure Index 显示，截至 2026 年 9 月 1 日，市场每百万 Token 的综合有效支出水平为 0.97 美元，最近七天下降 10%。这一读数处于该指数推出以来的低位，也明显低于今年夏季的阶段高点。

但看到“0.97 美元”，先别急着把它理解成“现在任何模型跑一百万 Token 都只要 0.97 美元”。这个指数不是某家厂商的价目表，而是把不同模型的价格和真实使用结构综合在一起，计算市场实际把钱花在了哪里。

## 指数下跌，可能有三种原因

Silicon Data 的方法说明显示，指数会受到三个因素影响。

第一是厂商直接降价。OpenAI 在 7 月 30 日调整 GPT‑5.6 Terra 和 Luna 的 API 价格，其中 Luna 的价格降幅尤其明显。这类公开调价会直接拉低市场成本。

第二是使用结构变化。即使某个旗舰模型一分钱没降，只要更多任务被迁移到便宜的小模型、开源模型或本地推理，市场的平均有效支出同样会下降。

第三是指数成分变化。新的模型进入主流使用范围，旧模型退出，输入与输出 Token 的占比发生变化，也会影响最终读数。

因此，指数反映的是“市场正在为什么样的 Token 付费”，而不只是厂商海报上的单价。

## 便宜模型正在接管大量日常任务

过去企业接入 AI 时，常常默认选择能力最强的模型，再想办法限制调用量。现在越来越多团队反过来设计：先判断任务难度，再决定应该把请求交给哪个模型。

例如：

- 文本分类、格式整理交给轻量模型；
- 普通摘要和客服问答交给低成本模型；
- 复杂编程、研究和关键决策才调用旗舰模型；
- 高重复、数据敏感的任务考虑开源模型或本地部署。

这类路由策略会让大量 Token 从高价模型流向低价模型。指数下降背后，既有供应商降价，也有采购方变聪明了。

## 为什么单价减半，账单可能没有减半

Token 变便宜后，产品往往会立刻做三件事：扩大上下文、增加重试次数、让 Agent 调用更多工具。以前舍不得跑的任务开始自动化，以前只生成一次的结果开始多轮校验。

结果是每百万 Token 更便宜了，但总 Token 用量可能增长得更快。

尤其是智能体工作流，一次用户请求背后可能包含规划、搜索、读取文件、调用工具、自我检查和最终整理。用户看到的是一条回复，系统实际可能完成了十几次模型调用。

所以企业真正应该看的是“每个完成任务的成本”，而不只是 Token 单价。

## 模型厂商的压力来自哪里

当基础推理逐渐商品化，模型厂商很难只靠“更聪明一点”长期维持高溢价。开源权重、国内模型和云平台之间的价格竞争，会持续压低普通能力的调用成本。

厂商仍然可以在几个位置保持利润：

- 最复杂任务的前沿模型；
- 更快、更稳定的优先推理；
- 企业安全、审计和数据隔离；
- 工具调用、代码执行与完整 Agent 平台；
- 面向具体行业的工作流和交付结果。

换句话说，未来更值钱的可能不是 Token 本身，而是“这些 Token 最终有没有把事情办完”。

## 开发者应该怎么利用这轮降价

如果你的产品正在使用大模型 API，可以马上做四件事。

1. 按任务记录实际输入、输出和缓存 Token，而不是只看月度总额；
2. 给简单任务设置便宜模型的默认路由；
3. 对高努力等级和长上下文设置明确上限；
4. 用成功完成一次任务的总成本比较模型，而不是只比较百万 Token 报价。

一个价格高两倍、但一次就完成任务的模型，可能比需要反复重试的便宜模型更省钱。反过来，让旗舰模型处理所有格式转换，也是在白白支付能力溢价。

## 我的判断

0.97 美元不是大模型价格战的终点，而是一个市场分层的信号。基础能力会越来越便宜，真正昂贵的部分会转向可靠性、速度、工具权限和对复杂任务的完成率。

普通用户会享受到更便宜的 AI；模型厂商则必须证明，自己卖的不只是一堆越来越便宜的 Token。
